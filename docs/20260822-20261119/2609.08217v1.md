## 摘要
视觉语言模型（VLM）在自动驾驶中展现出潜力，但仍存在幻觉、时空感知能力弱和泛化能力有限的问题。近期方法通过思维链（CoT）解释、检索增强生成或工具输出的静态注入来改进推理与决策。尽管这些机制丰富了上下文，但模型既不会主动感知场景信息，也不会在回答后积累经验。为克服这些局限，据我们所知，我们提出了首个将分层记忆与主动工具调用紧密耦合于闭环推理中的协同框架。我们的贡献有三方面。(i) 分层驾驶记忆：场景级短期记忆维护动态场景状态，而不断演化的长期记忆检索可复用的经验和工具策略。(ii) 记忆-工具协同推理框架：在场景状态和检索经验的引导下，模型在推理时自适应地调用工具以精炼其推理，并在离线阶段将可复用经验整合到长期记忆池中。(iii) 数据生成与两阶段训练流程：通过多步教师 rollout 构建的经校验的记忆-工具轨迹被用于监督微调（SFT）和 GRPO 训练。我们的 7B 模型在 DriveLMM-o1 上达到 80.03 的整体推理得分和 79.09% 的选择题（MCQ）准确率，超过最强基线 7.74 个 MCQ 百分点，并在多个基准上展现出强泛化能力。值得注意的是，消融和分析研究验证了每个组件的有效性，并进一步揭示了分层记忆的互补作用。短期记忆增强了时空理解，将 STSBench 准确率提升 24.2 个百分点，而离线长期记忆整合在所有参数冻结的情况下额外带来 3.57 个百分点的 MCQ 增益，展示了通过积累驾驶经验实现的持续自我演化。

## Abstract
VLMs have shown promise for autonomous driving, yet still suffer from hallucination, weak spatio-temporal perception, and limited generalization. Recent methods improve reasoning and decision-making through CoT explanations, retrieval-augmented generation or the static injection of tool outputs. Although these mechanisms enrich the context, the model neither proactively perceives scene information nor accumulates experience after answering. To overcome these limitations, we present, to our knowledge, the first synergistic framework that tightly couples hierarchical memory with proactive tool invocation in a closed reasoning loop. Our contributions are threefold. (i) Hierarchical Driving Memory: a scene-level short-term memory maintains the dynamic scene state, and an evolving long-term memory retrieves reusable experience and tool strategies. (ii) Memory-Tool Synergistic Reasoning Framework: guided by the scene state and retrieved experience, the model adaptively invokes tools to refine its reasoning at inference time and consolidates reusable experience into a long-term memory pool offline. (iii) Data Generation and Two-stage Training Pipeline: verified memory-tool trajectories built by multi-step teacher rollout are used to train with SFT and GRPO. Our 7B model reaches an overall reasoning score of 80.03 and MCQ accuracy of 79.09% on DriveLMM-o1, surpassing the strongest baseline by 7.74 MCQ points and generalizes strongly across benchmarks. Notably, ablation and analysis studies validate the effectiveness of each component and further reveal the complementary roles of hierarchical memory. Short-term memory strengthens spatio-temporal understanding, improving STSBench accuracy by 24.2 points, while offline long-term memory consolidation yields an additional 3.57-point MCQ gain with all parameters frozen, demonstrating continual self-evolution through accumulated driving experience.

## 1. 核心问题与研究动机

- **背景**：VLM 已被用于自动驾驶场景理解、高层行为决策与决策解释，但存在三类顽疾：幻觉、时空感知弱、泛化差。
- **现有三条技术路线的共同缺陷**：
  - **CoT 解释**：只是把单步预测展开成模板化的中间步骤，解释变长但理解未变。
  - **RAG 检索增强**：被动接收检索到的上下文，信息量增加但模型不主动求证。
  - **工具增强（如 AgentThink）**：把预计算好的工具输出一次性拼进 prompt，属于单向、静态注入，模型不主动感知、也不在回答后积累经验。
- **与人类驾驶的对照**：人类驾驶是"主动感知 + 时空理解 + 经验积累"的统一过程——靠**先见之明（foresight）**追踪自车与关键目标的运动趋势，靠**后见之明（hindsight）**调用长期积累的可迁移经验。
- **核心研究问题**：能否在一个统一的闭环推理框架中，同时实现时空感知、主动取证与经验积累，从而复现人类驾驶的先见与后见？
- **整体含义**：论文主张自动驾驶 VLM 研究应从"扩大静态感知与孤立推理"转向"可持续交互、随证据与经验演化的驾驶智能"。

## 2. 方法论

### 2.1 总体形式化

给定问题 q、六视角观测 I_t，策略 π_θ 以场景级短期记忆 M_s、从长期记忆 M_l 检索的 Top-K 条目 E_K、工具集 T 为条件生成答案：y ∼ π_θ(q, I_t, M_s, E_K, T)。模型迭代识别证据缺口、调用工具、累积观测，直至判定证据充分后作答。

### 2.2 分层驾驶记忆

- **场景级短期记忆 M_s**：
  - 用预训练 BEV 感知模型（HERMES 式）对相邻两帧 t−1、t 的环视图像编码，输出结构化语义描述 d_τ 与场景属性 n_τ（位置、定性关系、运动趋势）。
  - 组织为场景图 M_s = Φ_graph(d_{t−1}, d_t, n_{t−1}, n_t) = (V, R)，节点含自车、交通参与者、道路要素，边为空间/时间/交互关系。
  - 特点：仅在输入场景推进时刷新，单条轨迹内为只读场景先验；避免直接把多帧六视角图喂给 VLM 带来的上下文膨胀与隐式跨视角对齐负担。
- **跨场景长期记忆 M_l**：
  - 每条目 e_i = (c_i, r_i, p⁺_i, π^tool_i, w_i)，分别表示适用场景/任务条件、风险因素摘要、可复用成功推理模式、有效工具使用策略、检索效用权重。
  - 检索打分：S(e_i | q, M_s) = sim(E_m([q; M_s]), E_m(e_i)) + λ·w̄_i，取 Top-K；编码器为 all-MiniLM-L6-v2（384 维），返回 Top-4。
  - 两道防泄漏保护：排除与查询同场景的条目（避免检索到自身场景约 40 帧相邻帧）；返回视图剥离教师决策与数据集身份字段。
- **离线固化（sleep-time consolidation）**：
  - 从通过校验（答案正确性、工具调用合法性、推理–观测一致性）的轨迹中抽取经验缓冲 B⁺_n，经语义聚类、去重、冲突消解、抽象后合并入 M_l。
  - 效用更新：w_i ← w_i + η·g_i(C)，仅当该条目被检索且被验证者判定提供了有用引导时 g_i=1。
  - 关键点：在线推理期间 M_l 只读，固化完全离线，属严格归纳式自我演化。

### 2.3 记忆-工具协同推理（MTSR）

- 轨迹定义 C = (x₀, s₁, …, s_T, y)，每步 s_t = (h_t, a_t, o_t, u_t) 分别为推理状态、动作、工具观测、修正后的场景信念；u₀ = (M_s, E_K)。
- 每步 (h_t, a_t) ∼ π_θ(· | x₀, H_{<t})，a_t ∈ T ∪ {finish}；证据充分后输出 finish 并生成 y。
- 形成 **Think–Action–Observation–Update** 循环，无预设工具序列；记忆在单次查询内固定，仅瞬态场景信念随观测演化。
- 工具库共 27 个可调用函数（实验报告使用其中 20 个核心工具），覆盖：开放词表 2D 检测与指代实例选择、相机系 3D 定位、单目/成对深度与距离、前后车检测、自车状态、未来轨迹预测、占据栅格与地图/车道查询。

### 2.4 数据生成与两阶段后训练

- **多步教师 rollout**：教师策略（Qwen3.6-Plus，三阶段提示流水线：动作骨架规划 → 逐步决策 → 总结）在 gold 答案条件下生成工具执行轨迹；共 7,000 条，6,383 条通过校验。轨迹为"已知答案的解释"而非独立作答，故校验侧重动作合法性、观测来源、接地质量与一致性。
- **两阶段逐步 SFT**（LoRA，r=16, α=32，冻结视觉编码器）：
  - Phase 1：移除执行器返回的观测，只训练工具选择与参数生成（13,679 条记录，3 epoch）。
  - Phase 2：带完整记忆与工具反馈，学习基于观测的推理（20,062 条记录，20 epoch）。
  - 损失仅在模型生成的 token 上计算，环境返回的观测作为上下文被 mask。
- **轨迹级 GRPO**：每 prompt 采样 G=8 条轨迹，采用正确性门控的分层奖励（6 档）：正确+工具+引用记忆 +0.7；正确+工具无记忆引用 +0.5；正确无工具 0；错误+工具 +0.2；错误无工具 0；格式错误 0。作者明确说明 Tier 4 的小额正奖励是引导项与反捷径项，并论证其不可被利用（档位互斥、严格被支配、组内优势标准化）。训练分 v0–v3 四个续训阶段，v2 起注入 LTM。

## 6. 主要结论与发现

- **主结果**：7B 模型在 DriveLMM-o1 上推理得分 80.03、MCQ 79.09%，较 Qwen2.5-VL-7B 骨干分别提升 28.26 / 41.28 分；超同规模 AgentThink 7.74 个 MCQ 点；在 Rule Adherence 与 Scene Awareness 上排名第一。
- **跨基准泛化**：DriveMLLM 零/单样本 AccS 达 74.36 / 80.59（AgentThink 为 56.96 / 61.21），增益集中在接地与度量几何任务；未见过的 STRIDE-QA 上取得开放模型最佳 MLSR 3.9，长时程 2 s/3 s LSR 为 5.6 / 4.4。
- **后训练必要性**：两阶段 SFT 将推理/MCQ 从 51.77/37.81 提至 73.91/67.06；仅用 GRPO 不加 SFT 只得 73.85/64.49（MCQ 甚至低于 SFT），说明 SFT 冷启动是 GRPO 生效的前提。
- **记忆互补性**：无记忆 72.16% → +LTM 75.20% → +STM 76.91% → 两者结合 79.09%。STM 贡献更大（多数题依赖当前场景状态），LTM 增益较小但稳定。
- **时序表示**：原始 6 帧输入仅从 31.38% 提到 35.64%，而静态 STM 达 50.36%、时序 STM 达 55.61%——显式时序状态组织比堆叠视觉上下文更有效（STSBench 提升 24.2 分）。
- **持续自我演化**：冻结全部参数、仅做离线 LTM 固化，MCQ 从 79.09% 升至第 9 代的 82.66%（+3.57），第 10 代略降，显示记忆库饱和。
- **工具行为**：97.4% 查询使用 1–3 个工具，平均 2.10 次调用，仅 0.5% 无工具作答；工具执行成功率 99.74%，重复调用仅 0.45%，98.94% 轨迹正常终止——呈现任务相关、变长、可靠的交互，而非固定调用日程。
- **定性表现**：在远距测距、未来状态预测、恶劣天气决策、自车–目标空间关系等案例中，模型以工具证据接地（如 41.0 m vs 真值 45.22 m，基线仅 12.5 m），而非凭外观猜测。

## 7. 优点

- **问题定位清晰**：把"被动注入信息"与"主动取证 + 经验积累"的差别讲透，并用人类驾驶的先见/后见作为统一叙事框架，动机与方法高度自洽。
- **闭环设计完整**：在线"记忆条件化主动工具调用"与离线"经验固化"构成真正的闭环，且固化在参数冻结下即可带来增益，为持续演化提供了非参数的可行路径。
- **记忆分层有据**：STM 用 BEV 场景图而非原始多帧图像，既控制上下文成本又显式建模时空关系；消融证明这一设计选择优于"加帧"。
- **训练流程工程性强**：两阶段 SFT（先学调工具、再学用观测）+ 轨迹级 GRPO 的分工经消融验证；奖励设计对 Tier 4 引导项给出了结构性不可利用的三点论证，思考较深。
- **评测严谨度高于同类**：泄漏控制（同场景过滤、字段剥离、仅训练划分）、bootstrap 置信区间、对推理得分优势不显著的坦诚承认、超参未搜索的明确声明，均提升了可信度。
- **效率友好**：工具开销相对解码可忽略，整套系统可在单卡运行，具备实际可用性。

## 8. 不足与局限

- **实时性不足**：端到端中位延迟约 35 s/query，主要耗在 LLM 解码，作者自认适用于离线场景理解、数据标注与仿真评测，而非实时车载栈；论文以驾驶基准作为"接地多步推理"的测试床，不构成车辆就绪性主张。
- **奖励与目标错位**：强化阶段只优化选择题正确性，开放式推理质量仅靠 SFT 获得、无直接强化信号；Semantic Coverage-Step 仅 61.26，为最低维度（低于次低维度 13 分以上），反映推理循环在"足以区分选项"时即停止，牺牲了参考推理步骤的覆盖度。
- **统计与复现性**：主结果为单次确定性评测，区间不含训练方差；教师为无快照的 API 别名，轨迹不可重放；GRPO 采样不可比特级复现；固化实验仅一条轨迹，未刻画方差与渐近行为。
- **对比公平性存疑**：最接近的并发方法 DriveAgent-R1 因资产未公开而缺席对比；部分基线（如 GPT-4o、Qwen3-VL-32B）规模远大于本文 7B 模型，跨规模比较的解读需谨慎。
- **超参未调优**：学习率、LoRA rank、检索深度、组大小、交互预算均按算力预算固定，未做搜索，最优性未知。
- **度量精度有限**：定性案例中度量估计仍为近似（如 41.0 m vs 45.22 m、22.3 m vs 27.05 m），单目深度工具被作者自认为长距不可靠且调用极少（26 次）。
- **应用边界**：记忆固化在第 9 代后饱和下降，检索可靠性与信念冲突消解被作者列为下一步工作；向开放世界闭环驾驶的扩展尚未验证。
