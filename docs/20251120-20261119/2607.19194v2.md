## 摘要
自动驾驶的高层规划是一项知识密集型的工程决策任务，需要准确的场景理解、及时的推理以及内部一致的动作选择。视觉语言模型（VLM）能够将中间推理显式化，但其在已部署规划器中的应用受到以下因素制约：代价高昂的结构化监督、常规场景中不必要的推理，以及生成的推理依据与驾驶动作之间可能存在的不一致。我们提出了一种认知双过程规划框架，以机器可解析的结构化思维链（S-CoT）模式表示与规划相关的场景知识。一个自动化数据引擎集成了感知基础模型、关键路径过滤和专家VLM，无需对单条推理依据进行人工标注即可生成S-CoT监督。一个轻量级视觉仲裁器在语言解码之前从多级视觉编码器特征估计场景复杂度，并将每个输入路由至快速元动作预测或慢速结构化推理。对于慢速路径输出，一个确定性的基于规则的验证器检查解析出的S-CoT字段是否与最终元动作一致，并为组相对策略优化（GRPO）提供可验证奖励。在195个场景的人工审计中，生成的标注达到91.8%的CoT准确率和98.5%的逻辑一致性得分（LCS）。在574个经人工验证的NAVSIM测试样本上，该规划器达到80.14%的规划准确率和97.20%的LCS，同时相对于对每个场景均应用慢速推理，平均延迟降低了17.39%。在外部长尾子集上的评估进一步识别了路由与规划性能下降的条件。这些结果共同表明，显式场景知识如何通过自适应推理和基于规则的验证得以操作化，以支持高层VLM规划决策。

## Abstract
High-level planning for autonomous driving is a knowledge-intensive engineering decision task that requires accurate scene understanding, timely inference, and internally consistent action selection. Vision-language models (VLMs) can make intermediate reasoning explicit, but their use in deployed planners is constrained by costly structured supervision, unnecessary reasoning in routine scenes, and possible inconsistencies between generated rationales and driving actions. We present a cognitive dual-process planning framework that represents planning-relevant scene knowledge in a machine-parsable structured chain-of-thought (S-CoT) schema. An automated data engine integrates perception foundation models, critical-path filtering, and an expert VLM to generate S-CoT supervision without manual annotation of individual rationales. A lightweight visual Arbiter estimates scene complexity from multilevel vision-encoder features before language decoding and routes each input to either fast meta-action prediction or slow structured reasoning. For slow-path outputs, a deterministic rule-based validator checks whether the parsed S-CoT fields are consistent with the final meta-action and provides verifiable rewards for Group Relative Policy Optimization (GRPO). In a 195-scene manual audit, the generated annotations achieve 91.8\% CoT accuracy and a 98.5\% Logical Consistency Score (LCS). On 574 manually verified NAVSIM test samples, the planner achieves 80.14\% planning accuracy and 97.20\% LCS while reducing average latency by 17.39\% relative to applying slow reasoning to every scene. Evaluation on external long-tail subsets further identifies conditions under which routing and planning performance degrade. Together, these results show how explicit scene knowledge can be operationalized through adaptive reasoning and rule-based verification to support high-level VLM planning decisions.

## 1. 核心问题与研究动机

- **任务定位**：自动驾驶高层规划被界定为"知识密集型工程决策任务"，需同时满足场景理解准确、推理及时、动作选择内部一致三项要求。
- **端到端模型的局限**：直接学习"观测→动作"映射的端到端模型在长尾/分布外场景（交通参与者关系、道路结构、信号、路线约束）中性能退化，且恶劣天气或传感器退化会在下游规划前污染线索。
- **VLM 的潜力与三重部署障碍**：
  1. **规模化结构化监督成本高**：自由文本推理依据难以标注、难以转化为可复用/可验证的知识，缺乏连接"环境条件—关键对象—车道与路线约束—决策意图—最终动作"的机器可解析模式。
  2. **推理资源分配不当**：对所有场景施加完整 CoT 会抬高常规场景延迟；现有快慢架构/自路由方法多在自回归语言模型内部完成路由，与文本生成耦合，且对复杂场景的假阴性率缺乏控制。
  3. **推理—动作一致性不可验证**：生成的理由可能识别了危险却给出不兼容动作；标准 SFT 只学输出序列，不强制解析出的场景因素、推理意图与动作在统一交通约束下保持一致。
- **整体含义**：论文主张高层规划不应只是动作预测问题，而需要显式场景知识表示 + 自适应推理资源分配 + 推理与动作的一致性校验三者结合。

## 2. 方法论

### 2.1 核心思想
采用"认知双过程"架构：简单场景走快速元动作预测，复杂场景走结构化慢速推理；慢速路径的输出由确定性规则验证器检查一致性，并转化为可验证奖励用于 GRPO 强化学习。整体以 Qwen3-VL 为骨干，利用多层视觉编码器的 DeepStack 特征。

### 2.2 关键技术组件

- **S-CoT 结构化思维链模式**：固定字段模板，包含环境条件、关键对象、车道可用性、动作规划、简要推理；并引入 `uncertain`、`conditional` 等离散歧义标签以表达环境不确定性。
- **自动化数据引擎**（离线，无需逐条人工标注理由）：
  - *感知先验提取*：Grounding DINO 检测交通要素与动/静态对象，SAM 提供实例掩码，Depth Anything 提供相对深度。
  - *关键路径过滤*：用 VLM 过滤误检；再以未来自车轨迹投影出透视缩放的行车走廊，通过实例掩码与走廊的像素级交集区分"在路径上的关键对象"与"周边上下文"。感知模型与未来轨迹仅用于离线建数据，部署时不使用。
  - *专家标注与复杂度标注*：离线用 Qwen3-VL-235B-A22B 作专家标注器，部署规划器为微调的 Qwen3-VL-4B，二者分离以避免"自生成监督"。复杂度标签规则：仅当无遮挡巡航或稳定跟车且无周边威胁时标为 simple；存在环境风险、密度风险、策略交互风险三者之一即标为 complex。
  - *动作锚定的逆序标注*：离线先让专家预测离散元动作，再在固定动作条件下生成理由，最后重排为标准"先推理后动作"的推理序列，以减少理由与动作标签的矛盾。
- **解耦视觉 Arbiter（路由模块）**：
  - 轻量 Transformer，输入 M=4 个 ViT 层的特征（d_model=2560），使用 K 个可学习 query，其中首个为全局复杂度 token q_cls，其余抽取局部线索；局部 query 对拼接的多层特征做交叉注意力，自注意力在 query 间交换证据并聚合到 q_cls。
  - 分类头经 sigmoid 输出连续复杂度概率 P_complex；阈值 τ=0.7 时 P_complex ≥ τ 走慢路径。
  - 训练目标含假阴性惩罚：L_arbiter = L_BCE + w_r·L_risk，其中 L_risk = −C_r·log P_complex；C_r 在冻结 SFT 规划器下离线估计，由"快速路径动作与真值不符"和"快速路径动作违反验证器规则"两项加权构成（α=γ=1），训练期间固定，以避免路由与规划循环依赖。
- **监督微调（SFT）**：快路径用交叉熵直接学元动作；慢路径用分段加权交叉熵学完整 S-CoT 序列（段权重 w_t 与全局平衡系数 λ）。
- **RLVR + GRPO**：复合奖励 R = R_base + R_logic + R_risk。
  - R_base：S-CoT 格式合规 + 最终动作正确，含 sigmoid 长度惩罚抑制冗长，并对正确的非保守机动（如变道）加分以缓解过度保守偏置。
  - R_logic：奖励中间感知正确，并用规则验证器惩罚推理—动作矛盾。
  - R_risk：奖励高风险场景下的审慎行为，并奖励通过歧义标签恰当表达不确定性。
  - **确定性一致性验证器**：解析固定 S-CoT 槽位，按 9 条规则判定（如前方即时障碍必须减速/停车、红灯或停车标志必须停车、行人/弱势道路使用者必须减速/停车、近距前车禁止加速、目标车道不可用禁止向其变道、路线要求变道则必须向目标车道变道、存在不确定性时禁止加速、无约束且车道空闲时无理由停车/减速受罚、意图动词须与最终元动作兼容），无硬矛盾才通过。
  - GRPO 用组内相对优势 A_i = (R_i − mean)/std，配合裁剪策略损失与 KL 正则（相对 SFT 参考模型）。

## 6. 主要结论与发现

- **数据引擎质量**：完整引擎达 91.8% CoT 准确率与 98.5% LCS，优于单遍自回归流水线（80.5% / 88.7%）与模块化感知提示流水线；验证器与人工共识一致性标签吻合 96.2%。
- **主结果**：4B 模型达 80.14% 规划准确率、97.20% LCS、88.46% F1_per；相对 Qwen3-VL SFT 基线，LCS 提升 35.05 个百分点（62.15%→97.20%），规划准确率提升 9.41 个百分点（70.73%→80.14%）。零样本 VLM 仅 13.07%/17.77%，说明无任务微调时迁移能力有限；SFT 单独不能可靠保证推理—动作一致。
- **效率**：相对 Slow-Think 提升 2.27 个百分点准确率并降低 17.39% 平均延迟；相对 Fast-Plan 提升 6.27 个百分点准确率、延迟仅增 7.02%。
- **过度推理现象**：Slow-Think（77.87%）反而低于 Dual-Process（80.14%），说明在无遮挡巡航场景中完整推理链会把注意力引向周边实体、诱发对微弱或幻觉风险的反应；选择性路由可缓解此类失败。
- **长尾退化**：外部 6 子集平均路由 F1 75.55%、规划准确率 65.47%、FNR 25.10%，LCS 从 97.20% 降至 85.18%；交通标志推理（FNR 38.62%、准确率 56.88%）与低能见度（FNR 33.76%、准确率 59.72%）最差。失败模式为：雨雪导致小障碍被遮蔽、车道边界模糊，削弱 Arbiter 局部线索；标志常小而偏外围、与行车走廊交集弱，被关键路径过滤与 Arbiter 低估相关性。
- **消融结论**：R_logic 是一致性提升的主要贡献者（LCS 71.50%→96.96%，F1_per 77.68%→90.34%）；加入 R_risk 后准确率 79.27%→80.14%、LCS 96.96%→97.20%，但 F1_per 降至 88.46%（以少量感知指标换取更审慎行为）。SFT→RLVR 在三项指标上均最优；RL-only 无监督初始化时规划准确率仅 42.51%。
- **阈值权衡**：τ=0.6 时准确率略高（80.22%）且 FNR 更低（3.42%），但路由 F1 降至 72.35%、延迟升至 471.48 ms（慢路径过度使用）；τ=0.8 延迟降至 415.74 ms，但路由 F1 76.28%、准确率 78.56%、FNR 升至 12.02%。τ=0.7 为折中点。奖励权重超过 1.0 后 LCS 增益有限且准确率略降，提示过度加权验证项会诱发过度保守。

## 7. 优点

- **问题拆解清晰**：把 VLM 规划部署难题明确拆为"监督规模化、推理资源分配、推理—动作一致性"三个相互关联的子问题，并分别给出对应机制，结构对应性强。
- **路由与语言解码解耦**：Arbiter 在语言解码前基于多级视觉特征做连续复杂度打分，使路由决策可独立检查、阈值可连续调节，并以 FNR 作为显式优化目标（含假阴性惩罚与离线代价系数），比在自回归模型内部隐式路由更可控。
- **监督自动化且可校验**：数据引擎用感知基础模型 + 关键路径过滤 + 更大专家模型（235B 标注、4B 部署）分离，避免自生成监督；S-CoT 固定槽位使标注可在训练前被规则检查。
- **动作锚定的逆序标注**是实用技巧：先定动作再生成条件理由，直接降低理由与标签矛盾，同时保留部署时"先推理后动作"的顺序。
- **确定性验证器 + RLVR**：把领域交通规则转成可验证奖励，避免 LLM-as-a-Judge 的概率性噪声（对比实验中 LLM 评判 LCS 90.65% 低于 RLVR 的 97.20%），并同时服务训练奖励与评测 LCS，指标与优化目标一致。
- **实验设计较严谨**：验证/测试隔离、外部子集零泄漏、双人匿名审计并报告 κ 系数、失败案例定性图示、阈值与权重敏感性分析，且诚实报告了长尾退化与过度推理的反直觉发现。

## 8. 不足与局限

- **作者自述局限**：Arbiter 虽输出连续分数，但单次路由决策的视觉证据尚不可直接解释；S-CoT 模式与验证器仅覆盖固定场景因素，难以刻画罕见交互，尤其在严重视觉退化下；外部评估为定向子集而非全面跨数据集基准，泛化性未确立；仅预测离散元动作而非可执行轨迹，未验证闭环驾驶性能。
- **实验覆盖**：外部子集每类不足 110 条，长尾结论的统计稳健性有限；缺少多随机种子与置信区间；未报告训练时长、总算力成本与推理显存等部署关键指标；未与轨迹级规划器在同一闭环指标上比较。
- **偏差风险**：复杂度标签与 C_r 均依赖规则与离线 SFT 规划器，可能把 SFT 的偏置固化进路由；验证器规则由人工设定，规则未覆盖的场景可能被"通过"而虚高 LCS（LCS 本质是规则内一致性，不等于真实安全性）；训练数据全部源自 NAVSIM 日志分布，非公开长尾子集样本量小且来源不透明，复现性受限。
- **应用限制**：仅用前视单图 + 自车状态 + 导航指令，感知视野受限；元动作空间离散（横/纵向各若干类），与真实控制层之间仍需轨迹生成衔接；规则验证器需随交通法规与场景类型扩展维护，工程成本随覆盖面增长；τ 与奖励权重需针对部署场景重新调参（τ=0.6/0.8 的表现差异表明工作点对安全裕度敏感）。
