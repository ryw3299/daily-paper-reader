## 摘要
自动驾驶需要对细粒度3D场景事实进行可靠推理。对多模态驾驶观测进行细粒度问答为评估这一能力提供了自然途径，然而现有的感知流程和面向驾驶的大语言模型（LLM）方法仍存在场景事实不可靠、幻觉、推理不透明以及对任务特定训练的严重依赖等问题。我们提出KLDrive，这是首个用于自动驾驶细粒度问答的知识图谱增强LLM推理框架。KLDrive通过设计两个紧密耦合的组件来解决该问题：一个基于能量的场景事实构建模块，将多源证据整合为可靠的场景知识图谱；以及一个LLM智能体，在显式结构约束下于受限动作空间中执行基于事实的推理。通过将结构化提示与少样本上下文示例相结合，该框架无需大量任务特定微调即可适应多样化的推理任务。在两个大规模自动驾驶问答基准上的实验表明，KLDrive优于先前的最先进方法，在NuScenes-QA上取得65.04%的最佳总体准确率，在GVQA上取得42.45的最佳SPICE分数。在最具挑战性的事实推理任务计数上，它比最强基线提升了46.01个百分点，表明幻觉大幅减少，并证明了将可靠场景事实构建与显式推理相结合的优势。

## Abstract
Autonomous driving requires reliable reasoning over fine-grained 3D scene facts. Fine-grained question answering over multi-modal driving observations provides a natural way to evaluate this capability, yet existing perception pipelines and driving-oriented large language model (LLM) methods still suffer from unreliable scene facts, hallucinations, opaque reasoning, and heavy reliance on task-specific training. We present KLDrive, the first knowledge-graph-augmented LLM reasoning framework for fine-grained question answering in autonomous driving. KLDrive addresses this problem through designing two tightly coupled components: an energy-based scene fact construction module that consolidates multi-source evidence into a reliable scene knowledge graph, and an LLM agent that performs fact-grounded reasoning over a constrained action space under explicit structural constraints. By combining structured prompting with few-shot in-context exemplars, the framework adapts to diverse reasoning tasks without heavy task-specific fine-tuning. Experiments on two large-scale autonomous-driving QA benchmarks show that KLDrive outperforms prior state-of-the-art methods, achieving the best overall accuracy of 65.04% on NuScenes-QA and the best SPICE score of 42.45 on GVQA. On counting, the most challenging factual reasoning task, it improves over the strongest baseline by 46.01 percentage points, demonstrating substantially reduced hallucinations and the benefit of coupling reliable scene fact construction with explicit reasoning.

## 2. 方法论

### 2.1 总体架构
两个紧耦合阶段：(1) 能量化场景 KG 生成；(2) LLM 智能体在受限动作空间内做事实落地推理。

### 2.2 阶段一：能量化知识图谱生成
- **多源证据检测**：用 RayDN（相机）、FocalFormer3D（LiDAR）、IS-Fusion（融合）三个检测器分别产出原始证据集 $\mathcal{Y}^m_\tau$（含 3D 状态、类别、置信度）。
- **证据池化与恢复**：
  - *共识感知池化*：统一到 ego 坐标系、归一化置信度，按同类别 + BEV 位置/尺寸/朝向几何一致性关联，聚合为候选并保留来源集合 $\mathcal{M}^\tau_i$（provenance）。
  - *时序恢复*：短时窗内关联成 tracklet，对缺失帧用线性插值补全中心点：$\tilde{p}^\tau_i=(1-\alpha)p^{\tau^-}_i+\alpha p^{\tau^+}_i$，属性继承最近观测，置信度取相邻两帧均值。
- **能量模型精炼**：对候选集定义二元选择变量 $z^\tau_i$，总能量为四项之和：
  $$E=\sum_i z_i E_{\text{keep}}(i)+\sum_{i<j}z_iz_jE_{\text{pair}}(i,j)+\sum_i z_iE_{\text{attr}}(i)+\sum_i z_iE_{\text{sup}}(i)$$
  - $E_{\text{keep}}$：负的校准置信度 + 跨源佐证强度（按证据类型分参数校准）；
  - $E_{\text{pair}}$：惩罚冗余对（BEV 距离/重叠/类别一致）− 奖励时序一致对；
  - $E_{\text{attr}}$：$-\log p(a_i|v_i)$，约束运动状态与运动学证据一致；
  - $E_{\text{sup}}$：对时序支持不足或局部证据密度不足的候选施加铰链惩罚。
  - 通过最小化能量求最优子集，参数用池化候选上的二元监督学习。
- **场景 KG 生成**：精炼实体作为节点（属性含几何、运动、类别、置信度）；关系不显式物化全部边，而用关系算子库 $\Psi$ 按需计算（如几何算子输出相对位移与距离），仅实例化与查询相关的 $O(|V|^2)$ 子集，实现查询自适应构建。

### 2.3 阶段二：LLM 驱动的编排与推理
- **Plan–Execute–Observe 循环**：LLM 作为语义规划器逐步选择算子，执行器在 KG 上执行并回传落地观测，直至得到终止答案；复杂查询自然展开为多步符号轨迹。
- **受限场景查询代数（动作空间）**：
  - `Resolve(π)`：按属性谓词解析实体子集；
  - `RelSelect(U_ref, r, π)`：ego 中心六方向词表 {front, front_left, back_left, back, back_right, front_right}，按有符号 ego 角度量化方向，结果按最近优先排序；
  - `Intersect / Count / Exists` 集合运算；
  - `GetType / GetStatus / SameStatus` 类型化查询。
  - 中间变量必须为落地实体子集，引用集归约为确定性代表元 rep(U)。
- **上下文学习**：冻结 Qwen3-7B，不做任务特定微调；用结构化系统提示（角色、代数规范、推理规则、Question–Program 少样本示例）诱导规划行为。

- **整体性能**：NuScenes-QA 总体准确率 65.04%（超最强基线 MAPLM 4.87 点）；GVQA SPICE 42.45（最佳），METEOR/CIDEr 与最强微调基线相当；KLDrive-GT 达 84.49% 总体准确率，GVQA 三项指标全面最佳（43.89 / 0.43 / 3.88）。
- **计数任务是最大亮点**：KLDrive-KG 计数准确率 64.46%，较最强基线（MAPLM 18.45%）提升 46.01 点；LLM 类基线平均仅 13.60%，暴露严重幻觉。
- **感知保真度是关键瓶颈**：GT 场景下物体查询与比较分别提升 25.81 与 28.78 点；计数在 GT 下提升较小，说明其难点更多在组合推理执行而非事实质量。
- **难度分层**：H0 各类别均高（计数 85.10），H1 显著下降（计数 54.46），剩余瓶颈是多实体组合推理与复杂空间关系下的计数。
- **物体/属性差异**：属性类问题更稳（加权 61.50% vs 物体类 55.29%）；交通锥近饱和（99.6%），卡车/巴士等外观相似类别较难。
- **模块贡献**：无 EBM 精炼直接聚合多源检测仅 28.10%（提升 36.94 点）；KG 直接喂 LLM 端到端仅 44.38%（计数/比较分别差 58.21/26.49 点）；去掉 ICL 示例降至 71.54%，再去掉 Plan–Execute–Observe 循环降至 62.35%。
- **证据覆盖**：相机单模 40.98%、LiDAR 单模 40.18%、融合 77.01%，多源聚合 + EBM 精炼后达 88.19%，且 P/R/F1 全面优于原始融合候选。

## 7. 优点

- **问题定位精准**：将"事实可靠性"与"推理可解释性"作为耦合问题处理，而非单独优化检测或单独换更大 LLM。
- **方法设计有原则性**：EBM 将保留性、冗余、运动合理性、支持充分性统一为结构化子集选择目标，避免逐候选独立阈值化的脆弱性；provenance 集合保留使跨源佐证可量化。
- **推理可审计**：受限查询代数 + Plan–Execute–Observe 使每条答案可回溯到具体实体、属性与关系，契合安全攸关场景需求。
- **无需任务特定微调**：冻结 7B 模型 + 结构化提示 + 少样本示例即可适配多类任务，部署与扩展成本低。
- **消融归因清晰**：分别量化 KG 生成与 Agent 设计的贡献，并用 GT 变体隔离感知误差，论证链条完整。
- **工程细节扎实**：查询自适应关系实例化避免 $O(|V|^2)$ 全量物化；提供 A6000 与 Jetson 双平台延迟数据。

## 8. 不足与局限
