## 摘要
大语言模型（LLM）正日益被用作自动驾驶中的推理引擎，但其决策过程仍然不透明。我们提出通过反事实解释来研究其决策过程，即识别出改变驾驶规划所需的对场景描述的最小语义改动。我们提出 DRIV-EX 方法，利用连续嵌入上的梯度优化来识别翻转模型决策所需的输入偏移。关键在于，为避免无约束连续优化中常见的文本不连贯问题，DRIV-EX 仅将这些优化后的嵌入用作语义引导：它们被用于偏置一个受控解码过程，以重新生成原始场景描述。该方法有效地将生成引导至反事实目标，同时保证语言流畅性、领域有效性以及与原始输入的接近性，这些对可解释性至关重要。在 highD 数据集的文本转录上使用 LC-LLM 规划器进行评估，DRIV-EX 比现有基线更可靠地生成有效、流畅的反事实。它成功揭示了潜在偏差，并为提升基于 LLM 的驾驶智能体的鲁棒性提供了具体见解。代码可在 "https://github.com/Amaia-CARDIEL/DRIV_EX" 获取。

## Abstract
Large language models (LLMs) are increasingly used as reasoning engines in autonomous driving, yet their decision-making remains opaque. We propose to study their decision process through counterfactual explanations, which identify the minimal semantic changes to a scene description required to alter a driving plan.   We introduce DRIV-EX, a method that leverages gradient-based optimization on continuous embeddings to identify the input shifts required to flip the model's decision. Crucially, to avoid the incoherent text typical of unconstrained continuous optimization, DRIV-EX uses these optimized embeddings solely as a semantic guide: they are used to bias a controlled decoding process that re-generates the original scene description. This approach effectively steers the generation toward the counterfactual target while guaranteeing the linguistic fluency, domain validity, and proximity to the original input, essential for interpretability.   Evaluated using the LC-LLM planner on a textual transcription of the highD dataset, DRIV-EX generates valid, fluent counterfactuals more reliably than existing baselines. It successfully exposes latent biases and provides concrete insights to improve the robustness of LLM-based driving agents.   The code is available at "https://github.com/Amaia-CARDIEL/DRIV_EX" .

# DRIV-EX 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：LLM/VLM 正被广泛用作自动驾驶（AD）的端到端规划器，能直接根据传感器输入与用户指令生成驾驶决策，并常以 Chain-of-Thought（CoT）形式给出自然语言解释。
- **问题**：这类模型的决策过程仍然不透明；且已有研究表明 CoT 往往是"不忠实的合理化"，并不反映真正驱动预测的因果特征（Turpin et al., 2023），但仍有 63% 的近期自动驾驶系统论文把 CoT 当作可解释性方法（Barez et al., 2025）。在安全攸关场景中，这种不忠实解释可能掩盖危险行为的真实成因。
- **核心主张**：反事实解释提供了更"接地"的替代方案——通过找出**使模型决策发生翻转的最小输入改动**，显式隔离行为的因果特征。在驾驶 LLM 语境下，即寻找把"安全机动"变为"碰撞"（或反之）的最小场景描述修改，从而审计决策边界、暴露潜在安全风险。
- **技术难点（两难）**：
  - 基于梯度的连续嵌入优化能高效搜索决策边界，但投影回离散词表后文本往往不连贯（Kumar et al., 2022; Wen et al., 2023）；
  - 离散搜索/自回归采样保证流畅，却缺乏梯度引导，难以高效跨越决策边界；
  - 最小性约束难满足：缺乏正则时优化会漂移，幻觉出全新物体或上下文。

## 2. 方法论：DRIV-EX

### 核心思想
**解耦"反事实的搜索"与"反事实的生成"**：把梯度优化得到的连续嵌入**不当作最终输出**，而仅作为**语义引导**，去偏置一个受控的自回归解码过程，重新生成原始场景描述。由此兼得连续优化的搜索能力与自回归生成的连贯性。

### 问题形式化
- 设模型 $M$、词表 $V$，原始输入 $x^o=(x^o_1,\dots,x^o_m)$，输出 $y^o=M(x^o)$。
- 关注语义解码步 $T$（如结构化输出中第一个编码规划决策的 token；$T$ 是语义位置而非固定索引）。依据"自回归惯性"现象，控制第一个关键决策 token 通常足以重定向后续生成。
- 目标：求反事实 $x^{cf}$，使 $y^*_T$ 在步 $T$ 成为最优，同时保持流畅与语义邻近：
  $$\arg\min_{x\in V^m} c(x^o,x)\quad \text{s.t.}\quad y^*_T=\arg\max_{z\in V} P_M(z\mid y_{<T},x)$$

### 关键技术细节（算法流程）
1. **连续松弛**：为每个输入 token 维护软嵌入 $e=(e_1,\dots,e_m)$，由 $x^o$ 的嵌入初始化。
2. **投影**：每轮用余弦相似度把软嵌入投影到最近词表嵌入，得到离散序列 $x$：$x_i=\text{Proj}_E(e_i)=\arg\max_{v\in E}\frac{e_i\cdot v}{\|e_i\|\|v\|}$。
3. **决策驱动梯度更新**：计算决策损失 $L_{dec}(x)=-\log P_M(y^*_T\mid y_{<T},x)$，用**直通估计器（straight-through）**让梯度绕过离散投影，经 Adam 更新软嵌入 $e\leftarrow\text{Adam}(e,\nabla_x L_{dec},\eta)$。该"投影—前向—反向—更新"循环重复 $N$ 次。
4. **基于投影的正则化与评估（受控解码）**：用与 $M$ 同源、但仅做下一 token 预测（非规划适配）的**流畅性模型 $F$**（共享词表与分词），在贪心解码时对 logits 加偏置：
   - 距离向量 $b_{i,v}=\|v-\text{Proj}_E(e_i)\|_2^2$，归一化因子 $r_i=\|l_i\|_2/\|b_i\|_2$，偏置 $B_{i,v}=-w\cdot r_i\cdot b_{i,v}$；
   - 下一 token：$x_i=\arg\max_{v}(l_{i,v}+B_{i,v})$。
5. **输入邻近性正则（三种互补手段）**：
   - **Proj**：投影仅限 $x^o$ 的 top-$K$ 近邻；
   - **Loss**：在决策损失中加入 $(1-\frac{1}{m}\sum_i \cos\text{sim}(x_i,x^o_i))$，权重 $\lambda$；
   - **Bias**：用 $x^o_i$ 替代当前投影 token 计算第二偏置 $B'$，最终 $x_i=\arg\max_v(l_{i,v}+B_{i,v}+B'_{i,v})$。
6. **最优候选选择**：优先选成功翻转决策的候选，其中取与 $x^o$ 语义最接近者；若无翻转，则取目标 token 概率最高者。
7. **可选精修（附录 C.1）**：对连续被修改的 token 组尝试恢复初值，平均仅需一次额外批量推理，即可提升模板/相似度过滤与翻转率。

## 3. 实验设计

- **数据集/场景**：highD 数据集的**文本转写版**（Krajewski et al., 2018；Peng et al., 2024 发布），真实高速公路驾驶基准，含车道变换（LC）与轨迹标注；训练集 144,000 样本、验证集 24,000 样本。
- **被测规划器**：LC-LLM（Peng et al., 2024），LoRA 微调，分别基于 Llama3-8B、Mistral-7B、Qwen2.5-7B。
- **评测子集**：从验证集筛出 809 个"危险场景"（真值轨迹在 4s 恒速下潜在碰撞），再取模型预测为"安全"的样本；目标 $y^*_T$ 设为真值车道变换 token，即把"安全"翻转为"危险/碰撞"。更新仅限驾驶模板中可变的 token（车型、速度、位置等）。
- **对比基线**：DAB（Pynadath & Zhang, 2025）、PEZ（Wen et al., 2023）、GCG（Zou et al., 2023），以及任务适配版（†，加入本文邻近性正则）。
- **评价指标**：翻转率（目标 token 排名第一的比例）、最小流畅度、模板合规过滤率、BERTScore 过滤率（≥0.95）、聚合成功率 Aggreg（翻转+模板完美+高相似度三条件同时满足）、Aggreg & Col（成功且导致碰撞）。
- **算力预算对齐**：DAB/DRIV-EX 用 N=15 轮，PEZ 用 N=150 轮，GCG 用 N=6 轮（计算量约为前者 5 倍）。

## 6. 主要结论与发现

- **方法有效性**：DRIV-EX 在全部 3 个 LLM 上取得最高聚合成功率（Llama3 61.3%、Mistral 69.4%、Qwen2.5 34.4%），且相似度过滤率最高（Llama3 达 96.0%）。DAB 翻转率高但相似度差；PEZ 相似度好但流畅性差；GCG 在 Llama3 上较强（58.7%）但对其他模型敏感、性能随算力几乎不增长。
- **可扩展性**：DRIV-EX 是随计算量增长最明显的方法，第 15 轮即超过所有基线；PEZ 早期即饱和，GCG 超过 3 轮后几乎不提升。
- **正则协同**：Bias 与 Loss 各自带来提升（+2.7%、+6.7%），三者组合最佳（Aggreg & Col +8.0%）。
- **可回收注入偏差**：车型偏差下，偏差 token 被修改率 89.5%（无偏位置仅 8.0%），其中 84.2% 为"揭示偏差"的改动；数字偏差下偏差 token 修改率 52.9%，34% 为揭示性。
- **发现未知偏差**：Llama3 存在明显的**横向速度（vy）捷径**——vy 更负（约 −4.0 至 −0.47）会强烈偏向"右变道"，即使导致碰撞；也存在**纵向速度（vx）偏差**（vx>97 偏向"左变道"，可能源于训练集中超车与左变道的相关性）。Mistral、Qwen2.5 对 ego 速度也敏感，但更关注周围车辆（Qwen2.5 尤其关注他车速度与距离）。
- **可指导缓解**：去除横向运动学特征（no vy, ay）可在 F1/RMSE 基本不变的情况下减少碰撞；完全去除运动学（no v, a）大幅减少碰撞（753→631）但轨迹误差上升，体现性能与安全的权衡。
- **单 token 目标充分**：翻转后生成的变道类别与轨迹一致性在 Llama3 上达 100%，Mistral/Qwen2.5 均 ≥90%。

## 7. 优点

- **方法设计巧妙**：将"梯度搜索"与"离散生成"解耦，用优化嵌入仅作语义引导，从根本上规避了连续优化投影后文本不连贯的经典缺陷，同时天然满足流畅性、领域有效性与邻近性三重约束。
- **约束刻画细致**：提出 Proj/Loss/Bias 三种互补的邻近性正则，并有消融支撑其协同效应；用独立流畅性模型 $F$ 做 logit 偏置，保证与规划器共享词表。
- **评测公平性意识强**：基线同时提供原版与任务适配版，做了计算量对齐与缩放曲线，避免"算力换性能"的误判。
- **解释闭环完整**：不止于生成反事实，还做了"注入偏差回收→未知偏差发现→基于发现的去偏缓解"的完整链路，验证了方法的实用价值。
- **工程细节扎实**：附录给出指标阈值选取依据（BERTScore 阈值 95% 的统计论证）、超参搜索范围、精修步骤的低成本增益、许可证与数据合规说明。
- **可复现**：代码开源。

## 8. 不足与局限

- **仅支持文本输入**：无法直接处理图像/视频，扩展到 VLM 的图像反事实是重要未来方向。
- **白盒限制**：只能用于可访问梯度的模型，无法审计闭源 API 模型。
- **固定序列长度**：不能插入或删除 token，只能替换，限制了反事实的表达空间。
- **评测覆盖窄**：仅文本 highD + 单一刚性模板，未在自由文本或多样 NLP 任务上验证；作者自认框架虽通用但泛化性待证。
- **计算成本**：梯度搜索叠加自回归采样，单样本比纯梯度方法慢。
- **局部解释的聚合难题**：将个体反事实汇总为全局洞见依赖模板的结构化特性，难以推广到非结构化文本。
- **超参调优偏差**：直接在验证集上搜索超参且无独立测试集，存在乐观偏差风险；子集样本量小（部分分析 n<10），统计稳健性有限。
- **定位为离线审计工具**，不适合在线部署。
- **伦理双用风险**：方法可自动生成诱发危险驾驶的扰动，理论上可被用于攻击自动驾驶系统；作者主张受控披露是构建防御的前提，并提醒反事实只是近似诊断工具，不应视为模型逻辑的绝对保证。
