## 摘要
自动驾驶系统必须在部分可观测条件下运行，其中安全关键物体可能被遮挡或仅对邻近的网联车辆可见。车对车协同可以降低这种不确定性，但现有的协同驾驶方法通常将多智能体证据压缩为潜在特征或隐藏的多模态状态。因此，这些方法模糊了哪个智能体观测到了每个物体、该物体对自车是否可见，以及冲突证据如何影响下游决策。我们提出 G-MARK，一种接地多智能体推理框架，将协同的以物体为中心的观测转换为显式的来源感知知识图谱（KG）。所得知识图谱保留物体假设及其来源归属、自车与伙伴可见性、不确定性、冲突、空间关系和规划相关上下文。G-MARK 随后从这些知识图谱中导出共享特征表示，使轻量级任务头能够支持物体推理、运动预测、控制选择和轨迹预测。与最先进的基线相比，G-MARK 将遮挡推理准确率提高 42.2%，将控制选择误差降低 13.1%，并以小 25.6 倍的结构化通信负载实现可比的轨迹规划准确率。我们的代码可在 https://github.com/bhavyagupta98/g-mark 获取。

## Abstract
Autonomous driving systems must operate under partial observability, where safety-critical objects may be occluded or visible only to neighboring connected vehicles. Vehicle-to-vehicle cooperation can reduce this uncertainty, but existing cooperative driving methods often compress multi-agent evidence into latent features or hidden multimodal states. As a result, they obscure which agent observed each object, whether the object is visible to the ego vehicle, and how conflicting evidence affects downstream decisions. We propose G-MARK, a grounded multi-agent reasoning framework that converts cooperative object-centric observations into explicit provenance-aware knowledge graphs (KGs). The resulting KGs preserve object hypotheses together with their source attribution, ego-versus-partner visibility, uncertainty, conflicts, spatial relations, and planning-relevant context. G-MARK then derives a shared feature representation from these KGs, enabling lightweight task heads to support object reasoning, motion prediction, control selection, and trajectory forecasting. Compared with the state-of-the-art baseline, GMARK improves occlusion reasoning accuracy by 42.2%, reduces control-selection error by 13.1%, and achieves comparable trajectory-planning accuracy with a 25.6x smaller structured communication payload. Our code is available at https://github.com/bhavyagupta98/g-mark.

## 1. 核心问题与研究动机

- **背景**：自动驾驶必须在部分可观测条件下做安全关键决策，关键物体可能被遮挡、超出自车视野，或仅能被邻近网联车辆（CAV）观测到。V2V 协同可缓解这一问题。
- **现有方法的缺陷**：
  - 协同感知方法（早期/晚期/特征级融合，如 Where2Comm、V2X-ViT、CoBEVT）把多智能体证据压缩为潜在特征图或最终检测结果，**丢失了证据结构**：下游无法知道"哪个智能体支持该物体假设""自车是否直接看到""还剩多少不确定性"。
  - 语言/VLM 类协同推理方法（V2V-LLM、V2V-GoT）的中间状态是提示词、生成文本、自由推理链或隐藏多模态特征，**缺乏对象级结构化证据与可追溯性**。
- **核心主张**：协同驾驶不仅需要"物体是否存在"，还需要保留**来源（provenance）**——谁观测到、可靠性如何、为何对规划重要。论文据此提出 G-MARK，把协同目标级观测转成**来源感知知识图谱（KG）**，作为感知层之上的可复用推理层。

## 2. 方法论

### 核心思想
- **延迟不可逆融合（task-conditioned delayed evidence fusion）**：不把所有智能体观测合并成单一融合物体列表，而是把"观测智能体—局部观测—物体假设"作为相互链接的图实体保留，让不同任务头按需查询同一份协同证据。
- G-MARK **不直接消费原始相机/LiDAR**，而是抽象已处理好的协同感知产物（检测框/轨迹、位姿、置信度、规划上下文）。

### 四阶段流程
1. **协同 KG 生成**：
   - 每个智能体 $a_i$ 在时刻 $t$ 产生 $M_{i,t}$ 个局部观测 $o^{(i)}_{t,j}=(x,\tau,c,a_i,t,\eta)$（位置、语义类型、置信度、来源智能体、辅助属性）。
   - 节点集 $V_t=V^A_t\cup V^O_t\cup V^H_t$（智能体节点、观测节点、物体假设节点），边为类型化关系：source（来源）、support（支持）、空间关系（front-of/behind/left-of/near 等，自车坐标系）、规划上下文关系（near-trajectory、path-relevant）、证据一致性关系（cooperatively-supported、low-conflict）。
   - 假设节点 $h=(x_h,\tau_h,c_h,\pi_h,S(h),u_h,\gamma_h,r_h)$，其中来源记录 $\pi_h=\{(a_i,v^O_{t,i,j})\}$ 使每个假设可追溯到支持智能体与观测；可见性表示为**智能体相对关系** $vis(h,a_i)\in\{visible,occluded,uncertain\}$，而非全局标签。
2. **保守关联**：
   - 门控规则 $\delta_t=1$ 当且仅当语义类完全匹配且距离 $d(x_p,x_q)<\epsilon_{\tau_p,\tau_q}$（类相关阈值）；**精确类别匹配**是保守设计，避免跨类误合并造成不安全假设。
   - 亲和度 $\alpha_{t,pq}=1-d/\epsilon$（门控通过时），按空间一致性排序。
   - 融合位置为支持集内观测位置的**置信度加权平均**；置信度用有界 noisy-or 聚合 $c_h=1-\prod(1-c(v^O))$（仅作有界摘要，非标定概率融合）。
   - **未匹配观测不丢弃**，保留为弱候选（低支持、高不确定性），服务于遮挡与规划。
3. **协同上下文增强**：为每个假设构造增强向量 $\phi(h)=[\phi_{prov},\phi_{vis},\phi_{unc},\phi_{dis},\phi_{plan}]$，覆盖五类：来源与支持、智能体可见性、不确定性与可靠性、跨智能体分歧、规划相关性；最终特征 $\psi(h)$ = 物体状态属性 + $\phi(h)$。
4. **统一 KG 任务头**：$y_k=R_k(G_t,\{\psi(h)\})$，分三族——选择与可见性推理、运动与交互预测、控制与轨迹规划；$R_k$ 可为确定性检索/排序函数或轻量学习预测器。

## 3. 实验设计

- **数据集/场景**：V2V4Real（真实世界同步 V2V 场景，含物体标注、智能体位姿、时间戳、处理后感知产物）；**V2V-GoT-QA** 在其上扩展出 9 类任务（Q1–Q9）。官方划分约 **110K 训练 / 31K 验证**问题，在验证集上评测，任务定义与参考答案沿用 V2V-GoT。
- **任务与指标**：
  - 物体选择/可见性推理（Q1–Q4）：定位感知的 P/R/F1（0.5m 阈值）。
  - 运动/轨迹（Q5、Q7、Q9）：平均 L2 误差；智能体运动（Q6）：二分类准确率；控制选择（Q8）：归一化动作 L1 误差。
- **对比方法**：
  - 主基线：**V2V-GoT**（最接近的协同推理 SOTA，图思维链 + 多模态 LLM）。
  - 通信—精度分析（仅限未来轨迹预测任务）：No Fusion、AttFuse、V2X-ViT、CoBEVT、V2V-LLM、V2V-GoT。
- **实现细节**：KG 导出三类特征视图（物体检索 / 运动回归 / 场景-动作预测）；检索用共享逻辑回归排序器 + 任务 one-hot；运动用正则化回归头（Q5/Q7 共享、Q9 独立）；动作用轻量分类器（Q6）与独立速度/转向头（Q8）。

## 6. 主要结论与发现

- 9 个条目中 **8 个优于 V2V-GoT**：遮挡推理 F1 +42.2%（0.428 vs 0.301）、隐藏物体发现 +12.3%（0.494 vs 0.440）、可见物体 grounding +11.6%、物体运动 L2 改善 49.8–52.5%、智能体运动准确率 +3.5%、控制选择误差 −13.1%（0.076 vs 0.088）。
- **未来轨迹预测接近持平但略差**：L2 2.710m vs 2.620m（−3.4%），作者归因于长时程预测对速度、转向、曲率误差累积敏感。
- **通信效率显著**：G-MARK 仅 **0.0159 MB/样本**，比中间融合方法低约 25.2×、比 V2V-GoT 低约 25.6×，同时保持可比规划精度。
- **消融结论**：移除伙伴观测使隐藏物体 F1 从 0.494 降至 **0.000**（自车视角无法恢复仅伙伴可见物体）；移除来源使 F1 降至 0.396、控制 L1 升至 0.152；用扁平非图表示使 F1 降至 0.443、L1 升至 0.089——证明来源与图结构对推理和控制均有实质贡献。
- 结构化 KG 推理开销为毫秒级，约为已报道 VLM 类协同系统端到端延迟的 4–6%（非严格系统级对比）。

## 7. 优点

- **问题定位精准**：抓住"证据来源/可见性/冲突在融合中被抹除"这一被忽视但安全关键的缺口，表 I 的能力对比清晰刻画了与四类相关工作的差异。
- **表示设计合理**：智能体节点—观测节点—假设节点的三层分离 + 类型化关系，使来源可追溯；可见性建模为**智能体相对关系**而非全局标签，契合遮挡场景。
- **保守关联 + 弱候选保留**：精确类别匹配门控避免危险跨类合并；不丢弃未匹配观测，符合安全导向。
- **解耦表示与任务**：一次构图、多任务头共享查询，避免重型多模态推理，工程上轻量（CPU 毫秒级）。
- **通信效率突出**：25.6× 载荷缩减是协同驾驶落地的实际痛点，且用"每单位通信保留多少规划有用信息"来论证，指标选择有针对性。
- **消融设计有针对性**：Ego-only / No provenance / Flat non-KG 三个变体分别对应三条核心主张，结论干净（尤其 F1 归零的强证据）。

## 8. 不足与局限

- **算力与训练细节缺失**：无 GPU 型号/数量/训练时长，超参数（关联阈值 $\epsilon_\tau$、正则化强度、分类器设置）披露不足，复现性受限。
- **评测覆盖窄**：仅单一数据集/benchmark，无跨数据集或仿真闭环验证；未做闭环实车/仿真驾驶评估，安全性主张仍停留在离线 QA 指标。
- **基线公平性风险**：V2V-GoT 结果引自原文，未在同环境重训/重跑；G-MARK 使用轻量专用头而基线为 LLM 推理，任务适配程度不对等，部分增益（如运动回归 +50%）可能部分源于"数值回归任务更适合专用回归头"而非 KG 表示本身。
- **消融不完整**：未逐项剥离可见性、不确定性、分歧、规划相关性五个增强分量的独立贡献；消融仅 2 个任务。
- **轨迹预测未胜出**：长时程规划精度略逊于 V2V-GoT，说明 KG 条件表示对累积动力学误差的建模仍不足。
- **依赖上游感知质量**：G-MARK 消费"已处理"的感知产物，其性能上限受检测/跟踪质量约束；论文未分析上游噪声或通信丢包/延迟下的鲁棒性。
- **关联规则偏保守**：精确语义匹配 + 固定距离阈值可能漏关联（如部分遮挡导致的类别误判），论文未量化漏关联率。
- **延迟对比非严格**：与 VLM 系统的"4–6%"对比为跨系统间接比较，作者亦承认非直接系统级对比。
